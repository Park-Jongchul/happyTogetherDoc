1. 서비스 요약

‘행복하자 우리’는 네이버카페의 익숙한 게시판 구조를 모바일 앱에 맞게 재설계한 돌싱 커뮤니티입니다. 스플래시 이후 즉시 메인 ‘전체’ 탭을 보여주고, 공개 글은 비회원도 읽을 수 있게 합니다. 가입·정회원 인증은 댓글, 글쓰기, 모임 신청, 채팅, 보이스룸, 익명게시판처럼 권한이 필요한 행동을 할 때만 요청합니다.

핵심경험먼저 둘러보기가입 화면을 첫 진입에 강제로 노출하지 않습니다.
콘텐츠카페형 피드공지·인기글·가입인사·모임·전체글을 한 화면에 제공합니다.
관계텍스트+음성댓글, 단체채팅, 보이스룸으로 관계가 자연스럽게 깊어집니다.
신뢰돌싱 인증개인정보 노출을 최소화하면서 정회원 권한을 부여합니다.

8. 상세 화면설계서

화면의 번호 하나에 기능 설명 하나를 대응합니다. 각 설명은 동작·이동 경로와 조건·예외를 구분하며, 모바일에서는 설명을 화면 아래에 표시합니다.

설계서 읽는 방법

분홍색 번호는 해당 UI의 설명 번호입니다. 시계·통신 상태 등 OS 공통 요소는 번호에서 제외합니다. 반복 목록도 예시 항목마다 번호를 표시합니다. 번호는 각 화면에서 1부터 시작합니다.

권한 기준: 비회원은 공개 글 열람, 가입회원은 가입인사·댓글과 인증 신청, 정회원은 모임·익명게시판·채팅·친구추천을 이용합니다. D15 마이페이지는 로그인 회원부터 사용합니다. 권한은 서버에서 재검증합니다.

D17은 앱 기본 진입 화면, D05는 로그인 회원의 게시판 탐색 예시입니다. D12는 1:1 대화, D20은 단체채팅입니다. 같은 화면 안의 탭·패널·상태는 별도 화면 ID 없이 동작을 설명합니다. D24는 글쓰기·수정 공통 화면입니다.

공통 상태: 조회 중에는 스켈레톤, 빈 목록에는 조건 변경·작성 안내, 오류에는 재시도를 표시합니다. 서버 처리 실패 시 입력을 보존하고 중복 제출을 막습니다. 민감한 자료는 권한 범위와 보관 정책을 따릅니다.
